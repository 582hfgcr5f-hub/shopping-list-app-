What is included?

Supermarket and Costco item libraries and shopping carts, saved quantities, custom item photos, supper plans, menus, recipe ingredient edits, and supported saved preferences.

A test address and the live app have separate browser storage. Open this page at the same app address and in the same browser where your lists are saved. A backup from an empty preview will not contain the lists on your usual app.

This is a manual backup, not cloud sync. Save the downloaded file in a safe place; it can contain private notes and photos. Only supported shopping-app keys are included, never unrelated browser data. Restoring from a file is not enabled in this first version.
